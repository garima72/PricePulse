# PricePulse - Amazon Price Tracker 🛒

PricePulse is a Python-based price tracker that uses Selenium
and Tkinter to search for products on Amazon and filter them
according to the user's preferred price range.

The application allows users to search for different types of
products, such as laptops, headphones, keyboards, and more.

## Features

- Search for any product on Amazon.
- Set minimum and maximum price limits.
- Display up to 5 matching products.
- Show product names and prices.
- Display Amazon product links.
- Validate user inputs.
- Simple graphical user interface using Tkinter.
- Display a loading message while searching.

## 🛠️ Technologies Used

- Python
- Selenium
- Tkinter
- Chrome WebDriver

## ⚙️ Requirements

- Python 3
- Google Chrome
- Selenium

Install Selenium using:

pip install selenium

## 🖥️ Example

Product Name: laptop

Minimum Price: 70000

Maximum Price: 100000

The application searches for laptops within the selected
price range and displays up to 5 matching products.
